# 影视内容发行权窗口与实收结算核验平台

源提示词编号：10。维护作品、权利类型、地区、语言、窗口、独占和次级授权，联动时间轴与地区矩阵，检测重叠、交叉、倒挂和独占冲突，支持批量调窗、版本差异、评论锚点、审批和追溯导出。

新增「实收结算核验」：授权窗口、代理回传包与结算批次接入同一核验。

- 回传到达时按作品 / 地区 / 渠道匹配当时有效的授权快照（`snapshotAt`），窗口未生效或已过期直接阻断，过期窗口收入不计分成；收入期跨窗口按天折算。
- 授权窗口发布新版本时只重算受影响分成行（同 windowId 且批次未关账），其他代理人照旧；已关账批次保留历史行可查、不重算。
- 两笔回传同时提交时按包号排队；重复包号 + 相同内容指纹只入账一次；同包号不同内容的后到版本先留待人工核验。
- 处理失败以最近已确认包号为检查点，恢复时从失败包继续，冲回旧行而非新增行，同一笔收入不记两遍。
- 旧数据缺失授权快照时按原签署日期升级回填，回填后自动补核验，历史分成仍可查。
- 页面展示差异来源、待核验包号、阻断原因、检查点与核验日志。
